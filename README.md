# نضار للتنظيف بجدة — NADAR CLEANING
> **الموقع الإلكتروني الرسمي المتكامل لشركة نضار للتنظيف بمدينة جدة، المملكة العربية السعودية.**

موقع تجاري فاخر متعدد الصفحات مبني وفق أعلى معايير الويب الحديثة، ومصمم خصيصاً لتعزيز الحضور المحلي لشركة نضار في نتائج البحث بجدة، مع التزام تام بالسرعة العالية، إمكانية الوصول، وتجربة المستخدم الراقية.

---

## 1. نبذة عن المشروع والهوية البصرية

- **اسم العلامة التجارية:** نَضَار — NADAR CLEANING
- **النشاط:** خدمات تنظيف المنازل، الفلل، الشقق، المكاتب، المفروشات، والأسطح.
- **المدينة المستهدفة:** جدة، المملكة العربية السعودية.
- **اللغة والاتجاه:** العربية (`lang="ar"` و `dir="rtl"`).
- **الأسلوب البصري:** Editorial Premium يجمع بين المساحات العاجية المريحة، واللمسات الزمردية العميقة والتركوازية الأنيقة.
- **الخطوط:** خطي `Cairo` و `Tajawal` لأعلى وضوح ومقروئية على الشاشات الذكية والحواسب.

## 2. التقنيات المستخدمة (Tech Stack)

تم بناء الموقع دون أي أطر عمل ثقيلة (Zero Frameworks) لتحقيق أقصى سرعة تحميل، وضمان التشغيل المباشر على أي استضافة مشتركة:
- **HTML5 دلالي (Semantic HTML5):** بنية معيارية مهيأة لمحركات البحث وأجهزة قراءة الشاشة.
- **Tailwind CSS الإصدار 3.x:** مدمج ومضغوط محلياً في ملف `assets/css/style.css` بحجم **~34 كيلوبايت فقط** دون الحاجة لأي CDN خارجي في الإنتاج.
- **Vanilla JavaScript:** كود تفاعلي خفيف وسريع يتحكم في القوائم المنسدلة، قائمة الجوال، الأكورديون، والتحقق من النماذج مع دعم كامل للوحة المفاتيح وإمكانية الوصول.
- **SVG أصلي ومحسن:** شعار نضار وأيقونات الخدمات ورسومات الأزرار متجهة بالكامل لضمان أعلى دقة دون إبطاء الصفحة.
- **البيانات المنظمة (JSON-LD Structured Data):** تطبيق مخططات `HomeAndConstructionBusiness`, `LocalBusiness`, `Service`, `Article`, `FAQPage`, و `BreadcrumbList`.

## 4. تعليمات التشغيل والبناء محلياً

### المتطلبات المسبقة:
- توفر بيئة Node.js (الإصدار 18 فما فوق).

### الأوامر المتوفرة:

1. **تثبيت حزم التطوير (في حال الحاجة لإعادة التثبيت):**
   ```bash
   npm install
   ```

2. **بناء كافة صفحات الموقع وإعادة تجميع الـ CSS:**
   ```bash
   npm run build
   ```
   *يقوم هذا الأمر ببناء جميع ملفات الـ HTML الـ 27 وتوليد ملف `assets/css/style.css` المصغر بدقة.*

3. **بناء وتحديث ملف الـ CSS فقط:**
   ```bash
   npm run build:css
   ```

4. **تشغيل وضع المراقبة للـ CSS أثناء التعديل:**
   ```bash
   npm run watch:css
   ```

5. **فحص واختبار سلامة الموقع والروابط:**
   ```bash
   node ./scripts/test-site.js
   ```

6. **تشغيل خادم المعاينة المحلي:**
   ```bash
   node ./scripts/server.js
   ```
   *ثم افتح المتصفح على الرابط: `http://localhost:3000/`*

## 5. دليل الرفع على الاستضافة (Deployment Guide)

الموقع مبني بالكامل كملفات ثابتة (Static HTML, CSS, JS, Images)، مما يجعله جاهزاً للرفع فوراً على أي استضافة مشتركة تدعم cPanel أو خوادم Apache / LiteSpeed / Nginx:

1. **الرفع عبر مدير الملفات (cPanel File Manager) أو FTP:**
   - انقل جميع محتويات المجلد مباشرة إلى داخل مجلد `public_html` في الاستضافة.
   - تأكد من رفع ملف `.htaccess` (تأكد من تفعيل خيار *Show Hidden Files* في cPanel).

2. **إعدادات خادم أباتشي (.htaccess):**
   - تم تزويد المشروع بملف `.htaccess` عالي الأداء يتضمن:
     - تفعيل ضغط Gzip / Deflate لملفات HTML, CSS, JS, SVG.
     - تفعيل التخزين المؤقت للمتصفح (Browser Caching) حتى عام للصور والخطوط.
     - قواعد التوجيه النظيف وحذف لواحق `.html`.
     - توجيه مسار الخطأ المخصص `ErrorDocument 404 /404.html`.
     - ترويسات الأمان الأساسية (`X-Content-Type-Options`, `X-Frame-Options`, إلخ).

## 7. بيانات ينبغي لصاحب النشاط استكمالها قبل الإطلاق الفعلي

حرصاً على مبادئ الشفافية التامة وعدم اختلاق أي بيانات وهمية، تم تجهيز مواضع واضحة وموحدة للبيانات التالية لتعديلها عند تدشين الموقع برقم الهاتف الرسمي:

1. **رقم الهاتف الرسمي:** تم استخدام الرقم الافتراضي الموحد `0500000000` (وفي الرابط الدولي `+966500000000`)؛ لتغييره عالمياً افتح ملف `scripts/template.js` وعدّل المتغيرات `PHONE_DISPLAY` و `PHONE_INT` ثم نفذ `npm run build`.
2. **رابط واتساب الرسمي:** تم ضبطه على `https://wa.me/966500000000` ويتم تحديثه تلقائياً من نفس الملف السابق.
3. **البريد الإلكتروني:** تم تعيين `info@nadarclean.com`.
4. **تفعيل استقبال رسائل النماذج عبر البريد الإلكتروني:**
   - حالياً يقوم نموذج الحجز في صفحة الاتصال وصفحات الخدمات بالتحقق من صحة رقم الجوال السعودي والبيانات، وتجهيز رسالة واتساب مفصلة بضغطة زر واحدة.
   - في حال الرغبة باستقبال الرسائل مباشرة عبر البريد الإلكتروني، يتم ربط وسم `<form>` بنقطة نهاية مخصصة (مثل خدمة Formspree أو سكربت بريد PHP على استضافة cPanel الخاصة بالشركة).
5. **معرض الصور النهائي:** الصور الحالية هي صور فوتوغرافية مرخصة للاستخدام التجاري المجاني من Unsplash؛ يمكن لصاحب النشاط في أي وقت استبدالها بصور واقعية لفرق العمل ومشاريع الشركة المنجزة بجدة داخل مجلد `assets/images/`.
